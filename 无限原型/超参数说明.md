优化器 `model.__init__` 的 lr 默认 .01 未参与 Trainer 的取值；实际是 `engine.py` 显式传 .001。原 demo 配置中的 weight_decay=.0001 未传到这个训练器，实际普通组为 .001。组成员按参数类型判定，不把全部双曲模块或全部 BN 参数都称作零衰减。共享 `std` 参数虽被创建，但冻结作者 BN 前向未使用它；不能把声明的 learn_std 直接解释为有效标准差学习。

实际前向（尺寸为静态推导）：

```text
[B,32,7500]
→ unsqueeze [B,1,32,7500]
→ 时间Conv2d 1→8，kernel(1,64)，pad(0,32)，stride1，无bias
  [B,8,32,7501]
→ 欧氏BN
→ 电极Conv2d 8→16，kernel(32,1)，groups8，无bias
  [B,16,1,7501]
→ 欧氏BN → ELU → AvgPool(1,4),stride4 → Dropout .25
  [B,16,1,1875]
→ ec1深度时间卷积，kernel(1,16)，pad(0,8)，groups16，无bias
  [B,16,1,1876]
→ permute → 逐位置特征L2归一化 → 双曲表示
→ 双曲1×1卷积（16空间特征）→ 域BN → 双曲ELU
→ 双曲AvgPool(1,8),stride8：234个时间位置
→ 流形flatten：D1 [B,3745]；D2 [B,3744]
→ 官方BMLR → [B,9]
```

`block2` 还在模型注册状态中，用于构造期 `feature_dim()` 推断维度并消耗原 RNG；正式 `forward` 走的是 `ec1→lc1→bn→elu→avpool`，不能把 block2 当成又执行一遍的第二块。母版旧 HMLR 构造所消耗的随机数同样保留，然后才换成 CPU float64 初始化的 BMLR；删除“未使用模块”会破坏原初始化配对。

BN 在每个 epoch 开始按原公式取值。令 `rho=(10/50)^(1/90)`、`w=max(90-e,0)/89`，则 `eta=1−(rho^(90w)−rho^90)`，模块实际 `eta_test=.85^(.2(1−w)+w)`。e=0 的 eta 约1.003584，e≥90 时 eta=.2、eta_test≈.968019。初轮略大于1来自原公式，本包未裁剪或重解释为普通 torch momentum。100 是训练上限，90 是 BN 时间参数，二者不能混用。

D2 另外保持其冻结实现的球投影上限 `1−1e-8`、零向量缩放阈值 `1e-15`、质心分母下界 `1e-8`、BallMean 最多100次/绝对或相对1e-12停止。D1保留全部作者几何算子与保护值。它们在 `hyperparameters/operator_defaults.json` 中附有声明位置索引；该索引列出的其他未调用默认值不等于实际协议。

恢复保存模型/优化器/RNG/BN别名和状态/早停/BN调度器/epoch边界；不从旧训练权重初始化新折。没有 warmup、额外材料头、锥损失、LDS 或后接 MLP。数据未提供、本次不运行模型，因此这里的尺寸是代码静态推导，数值稳定性与新机器容量需要使用者在目标环境验证。

## v2 完整 loss 观察口径（不改变科学超参数）

每个实际 step 记录原 CE、域求和 raw HHSW、权重 .01、原 weighted HHSW、原 total、真实参数组 LR、ID/域数/样本数。epoch 主值统一按 optimizer step 等权平均，另列 CE 样本加权均值；不重算 epoch 点云 HHSW。原 train_eval/sourceval 只计算 CE/BA，HHSW/total 明确为空。LR 仍恒定 .001，现有 scheduler 是 BN 时间调度，没有新增 LR scheduler/warmup/clip。详见 [LOSS_LOGGING.md](LOSS_LOGGING.md)。
